BLOKZ

VERILOG · CYCLONE IV FPGA

A hardware-level Tetris game engine written in Verilog with VGA-to-HDMI direct driving on an Altera Cyclone IV board.

Real-time hardware demonstration running at 60Hz output to an HP E27 G5 monitor.

Architecture

VGA Sync & Hardware Timing

The HP E27 G5 monitor only accepts digital HDMI input, which isn't directly compatible with the FPGA's 3.3V GPIO pins. To bridge this, I routed the digital signals into an active Steren VGA–HDMI converter to translate the timing into HDMI data. In Verilog, custom counters in vga_sync drive the pixel timing. When the monitor initially threw an "Input Signal Out of Range" error, I tuned V_TOTAL and the vertical blanking parameters until the 24 MHz clock produced a stable frame.

02
Game Logic

LFSR & State Machines

Implemented a 7-bit Linear Feedback Shift Register (LFSR) for pseudo-random tetromino generation, alongside synchronous finite state machines for gravity, collision checks, and row clearing.

03
Graphics

Font Engine & Grid Renderer

Built a lightweight combinational font ROM for score displays and splash screens, plus a 20×10 block matrix pipeline rendered in parallel hardware cycles.

04
Validation

Debouncing & Hardware Testing

Built hardware debouncing filters using 20-bit counters to stabilize key input signals on the physical board switches, and resolved FPGA pin reservation conflicts during synthesis.

  • Randomization: 7-bit LFSR (x⁷ ⊕ x⁶) for piece generation.
  • Board memory: A flat 200-bit register array manages the 10×20 grid with no external RAM.

Digital Logic

How It Works: Bits to Pixels

Direct Binary Color Mapping

Every pixel on screen is pure binary logic evaluated on the fly each clock cycle. Without external video RAM or a GPU, each RGB channel is driven by a single FPGA GPIO pin (1-bit per color), giving 8 distinct color combinations:

// Verilog: real-time RGB bit assignment
case (anim_shape_id)
  3'd1: {vga_r, vga_g, vga_b} = 3'b011; // Cyan    -> Piece I
  3'd2: {vga_r, vga_g, vga_b} = 3'b110; // Yellow  -> Piece O
  3'd3: {vga_r, vga_g, vga_b} = 3'b101; // Magenta -> Piece T
  3'd5: {vga_r, vga_g, vga_b} = 3'b100; // Red     -> Piece Z
  default: {vga_r, vga_g, vga_b} = 3'b000; // Off
endcase

FPGA to Monitor

At 24 MHz, the rasterizer calculates pixel_x / pixel_y and outputs 5 digital TTL signals over GPIO: HSYNC, VSYNC, and the RGB bits.

  • FPGA output: raw 3.3V square waves streamed bit-by-bit as the scanline traverses the screen.
  • Steren adapter: samples the 3.3V logic levels, locks onto the sync timing, and recodes it into differential TMDS packets.
  • HP monitor: decodes the TMDS stream from HDMI and lights up the display in real time.
